Mailpilot APT repository

Debian / Ubuntu (amd64). Install:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://iqbalsound.github.io/mailpilot/mailpilot-archive-keyring.gpg | sudo tee /etc/apt/keyrings/mailpilot.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/mailpilot.gpg] https://iqbalsound.github.io/mailpilot stable main" | sudo tee /etc/apt/sources.list.d/mailpilot.list
sudo apt update && sudo apt install mailpilot

Source: github.com/iqbalsound/mailpilot
